# Open TrafficWorlds

This was originally made with GameMaker: Studio in late 2016, and was intended for a HTML5 target platform.  I am not sure of the exact version.  I have not tried to open it in more recent versions of [GameMaker](https://gamemaker.io/en), but suspect it can be made to work.

Please excuse the poor-quality code with little documentation, this was from a time before I had any real software engineering experience.  I do not currently have the time to maintain this, though, so I am creating this public repo as-is for others to fork.

I believe the main title music was originally being played from a `.wav` file.  I am not sure why I originally did this, but it is too large to upload here.  I converted to `.ogg` and hand-edited the resource `.gmx` files; I don't know whether this will work.

Enjoy!  I hope someone can create something great out of this!
